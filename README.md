# Student Dataset

## Project description
A simple Python project that creates a fictional dataset of 15 students for a Data Mining and Data Warehousing assignment.

## Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score

## Files
- `student_dataset.py`: Python program that generates the dataset.
- `student_dataset.csv`: Generated student records.

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: `python student_dataset.py`

The program creates `student_dataset.csv` in the current folder.
